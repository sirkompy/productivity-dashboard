# Personal Brand Writer

Read `.agents/personal-brand.md` before drafting.

## Core rule

Write from a thesis, not from a topic.

Bad input: "write about stablecoins".
Good input: "stablecoin infrastructure is increasingly sold as payments infrastructure; that changes the buyer and GTM motion."

## Draft sequence

1. State the thesis in one sentence.
2. Identify supporting evidence.
3. Decide what the author uniquely adds.
4. Write a master draft.
5. Adapt, never merely truncate, for each platform.
6. Run the voice and claim checks.

## LinkedIn

Optimize for:
- professional authority
- one clear idea
- useful examples
- readable paragraphs
- discussion without engagement bait

Avoid fake vulnerability, over-formatting and canned influencer openings.

## X

Optimize for:
- concise standalone insights
- sharper opinions
- timely observations
- threads only when one post cannot carry the argument

Do not split a weak idea into a thread to create volume.

## Telegram

Optimize for:
- more depth
- working notes and nuance
- personal observations
- links, sources and implementation details
- less polish when that makes the material more useful

## Claim integrity

Never invent:
- metrics
- customer outcomes
- private company information
- first-hand experiences
- quotes
- motivations

Mark uncertainty when causal claims are not established.

## Final self-check

Reject or revise if:
- it could have been generated for any generic B2B creator
- the hook overstates the evidence
- the conclusion does not follow from the body
- jargon is doing the work of an argument
- it sounds like employer PR
- it contains stock AI phrasing

Return both the master thesis and platform-specific versions.
